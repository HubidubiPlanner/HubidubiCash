Build it yourself

You need a JDK 17. For the phone app, the Android SDK too.

  1. Get the source

    git clone https://github.com/HubidubiPlanner/hubidubicash.git

  2. Build the phone app

    cd hubidubicash/src/apps && ./gradlew :android:assembleDebug, then install the APK it makes on your phone.

  3. Or the computer app

    ./gradlew :desktop:packageDmg on a Mac, ./gradlew :desktop:packageDeb on Linux.
